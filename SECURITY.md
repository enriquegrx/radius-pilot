# Security policy 🔐

RadiusPilot changes VPN authentication, so security reports deserve a private
conversation before they become a public issue.

Please use GitHub's **Report a vulnerability** button in the repository's
Security tab. Include the affected version, a concise reproduction, and the
impact you observed. Do not include live passwords, RADIUS shared secrets, Duo
keys, activation links, private addresses, or production logs in an issue.

The project currently supports the latest release on `main`. We aim to
acknowledge a report within three working days. Timing for a fix depends on the
risk and whether a safe migration is required.
